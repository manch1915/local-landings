# Как поменять тексты, цены и расписание

Все тексты сайта лежат в одном файле на каждый лендинг. Код трогать не нужно.

| Сайт | Файл |
|---|---|
| Ремонт квартир «Отвес» | `apps/repair/src/content/ru.yaml` |
| Репетитор, русская версия | `apps/tutor/src/content/ru.yaml` |
| Репетитор, английская версия | `apps/tutor/src/content/en.yaml` |
| Фитнес-студия «Каденс» | `apps/fitness/src/content/ru.yaml` |

## Что можно править

- **Тексты**: заголовки, описания услуг, отзывы, вопросы и ответы. Меняйте текст после двоеточия.
- **Цены**: просто число, без пробелов и знака рубля: `price: 2200`. Калькулятор ремонта и подбор курса пересчитаются сами.
- **Расписание студии**: одна строка на занятие.

  ```yaml
  - { day: 3, time: '19:00', direction: box, trainer: marina, minutes: 55, spots: 2 }
  ```

  `day` это день недели (1 понедельник, 7 воскресенье), `spots` это свободные места. Если мест нет, поставьте `0`, на сайте появится «мест нет» и запись в лист ожидания.
- **Контакты**: телефон, адрес, ссылки на мессенджеры в блоке `site`.

## Правила, о которые легко споткнуться

1. Отступы делаются пробелами, не табуляцией. Сдвиг строки меняет смысл.
2. Если в тексте есть двоеточие с пробелом, возьмите весь текст в кавычки:
   `- 'Говорим о том, что интересно: игры, сериалы'`.
3. Длинный текст можно переносить так, после `>-` все строки склеятся в один абзац:

   ```yaml
   text: >-
     Первая строка абзаца
     и его продолжение.
   ```

## Что будет, если ошибиться

Сайт просто не соберётся, а в логе сборки будет написано, какое поле и в каком файле не так. Например:

```
page → ru data does not match collection schema.
courses.5.points.1: Expected type "string", received "object"
```

Это значит: в списке `courses`, у шестого курса, во втором пункте `points` что-то не так (чаще всего двоеточие без кавычек). Старая версия сайта при этом продолжает работать.

## Как опубликовать изменения

После правки файла на сервере запускается `docker compose up -d --build web`. Если править файл прямо на GitHub, CI соберёт сайт на каждом коммите, и ошибка будет видна до выкладки.
